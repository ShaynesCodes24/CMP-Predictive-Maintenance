## 45-Second Video Walkthrough Script

```text
This is my CMP predictive maintenance dashboard.

I built it to practice semiconductor equipment technician workflows using Python, synthetic CMP tool data, and Streamlit.

At the top, the dashboard summarizes tool health, recent alert volume, and maintenance event history.

The tool priority cards show whether each CMP tool is normal, warning, or maintenance-needed, along with pad life, retaining ring life, removal rate, and process drift.

The sensor trend chart lets me inspect signals like platen motor current, vibration, slurry flow, wafer removal rate, and process drift. The vertical markers show simulated maintenance events and reset behavior.

The alert table translates abnormal trends into technician checks, such as inspecting slurry delivery, vibration sources, pad condition, retaining ring wear, alarms, and process drift.

The model tab shows predicted maintenance state, confidence, review priority, and feature importance.

The main goal is not just model accuracy. It is to connect equipment behavior, sensor trends, and technician action.
```

## How To Explain The Accuracy

```text
The model reached 99.877% test accuracy on synthetic data. I do not treat that as a production claim. The high score makes sense because the data is simulated and includes explainable domain-threshold features that match the maintenance labels. In a real fab setting, I would validate the model with real equipment logs, maintenance work orders, process history, and technician feedback.
```
